Attack Abilities

Laser Beam

Category: Attack

Energy Cost: 10

Cooldown: 5 ticks

Description: Fires a continuous straight laser across the arena.

Effect: Damages all entities in its path. Can interact with colored orbs for bonus effects.

Code / Pseudo-Code:

struct Laser { intensity: 5; width: 1; duration: 3; }

Super Ball

Category: Attack

Energy Cost: 15

Cooldown: 7 ticks

Description: Bounces around the arena, hitting multiple targets.

Effect: Deals 3 damage per hit, can hit up to 5 entities.

Code / Pseudo-Code:

struct SuperBall { bounces: 5; damage: 3; }

Wave

Category: Attack

Energy Cost: 12

Cooldown: 6 ticks

Description: Sends a horizontal energy wave across the field.

Effect: Knocks back enemies, deals 2 damage.

Code / Pseudo-Code:

struct Wave { speed: fast; damage: 2; knockback: 1; }

Ally / Orbital Drones

Basic Drone

Category: Ally / Orbital

Energy Cost: 20

Cooldown: 8 ticks

Description: Circles the player, ramming enemies on contact.

Effect: Deals 3 damage, has 3 HP, destroyed on enough damage.

Code / Pseudo-Code:

struct OrbitalDrone { HP:3; orbit:true; damage:3; behavior:ram; }

Scrap Drone

Cooldown: 10 ticks

struct OrbitalDrone { HP:2; orbit:true; collect:true; damage:2; }

Summon Orb

Category: System / Spawner

Energy Cost: 15

Cooldown: 10 ticks
